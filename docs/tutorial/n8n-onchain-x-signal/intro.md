链上数据（On-Chain Data）是指区块链网络中公开记录的所有交易、地址余额、智能合约交互等信息，具有不可篡改、实时性和透明性，是加密市场分析的核心基础。

通过分析链上数据，我们能洞察资金流动、巨鲸行为和市场趋势，从而制定更精准的投资策略。

在波动剧烈的加密货币市场中，捕捉巨鲸操作往往是领先一步的关键。

利用n8n开源自动化工具，构建了一个全链路智能监控系统：

通过定时拉取区块链API（如Etherscan或Alchemy）实时扫描大额交易，智能过滤巨鲸行为（如>100 ETH转账）；

同时集成X（Twitter）高级搜索，捕捉相关地址或代币的KOL讨论与FOMO信号；

进一步调用LLM大模型（如GPT-4o或Grok）综合分析链上意图与社交情绪，生成结构化跟单建议——包括买入/卖出推荐、置信度评估、仓位比例及止损点位。

最终，所有警报与决策推送至Telegram频道，支持一键执行DeFi操作。

该系统自托管免费、扩展性强，助力散户化身为数据驱动的"鲸鱼猎手"，从被动警报升级为主动策略引擎。

### 目标

将链上数据（客观资金流动）、社交信号（特朗普的"总统效应"推文）和AI分析（Groq的高速LLM）融合，生成可靠的跟单建议。
