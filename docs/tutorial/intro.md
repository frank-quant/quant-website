# 入门教程

欢迎来到 Frank Quant 入门教程！这里提供了系统化的量化交易学习路径，从零开始带你掌握加密货币量化交易的完整流程。

## 📚 教程目录

### 1. 跑通第一个量化程序

从零开始，手把手带你使用 **Freqtrade** 完成第一个量化交易程序，体验量化交易的完整流程。

- [开始学习 →](./run-first-quant-program/intro)

**学习内容**：
- 🔧 搭建基于 Docker 的 Freqtrade 量化交易环境
- 💡 理解和编写交易策略（基于 RSI、TEMA、布林带等指标）
- 📈 进行策略回测和性能评估
- 🚀 将策略部署到实盘交易
- 📱 配置 Telegram 机器人实时监控交易

### 2. AWS部署freqtrade

在 AWS 云平台上部署 Freqtrade 量化交易系统的完整指南，实现 7x24 小时自动化交易。

- [开始学习 →](./aws-deploy-freqtrade/intro)

**学习内容**：
- ☁️ 在 AWS EC2 上创建和配置云服务器实例
- 🐳 在 Linux 服务器上搭建 Docker 环境
- 🚀 部署和配置 Freqtrade 量化交易系统
- 🔒 配置安全组、密钥对等安全措施
- 📊 设置监控和日志管理

### 3. Freqtrade相关

深入了解 Freqtrade 的数据库结构、异常处理等高级主题。

- [开始学习 →](./freqtrade-related/intro)

**学习内容**：
- 📊 SQLite 数据库表结构详解
- 🔧 异常数据处理和清理
- 💡 高级查询和分析技巧

### 4. n8n+链上数据监控

利用 n8n 开源自动化工具，构建全链路智能监控系统。

- [开始学习 →](./n8n-onchain-monitoring/intro)

### 5. n8n+链上监控+X监测=》跟单信号

将链上数据、社交信号和AI分析融合，生成可靠的跟单建议。

- [开始学习 →](./n8n-onchain-x-signal/intro)

**学习内容**：
- 🔗 链上数据监控和分析
- 📱 X（Twitter）信号捕捉
- 🤖 LLM 大模型综合分析
- 📊 结构化跟单建议生成

## 🎯 学习建议

1. **按顺序学习**：建议从"跑通第一个量化程序"开始，这是最基础的教程
2. **动手实践**：每个教程都包含详细的步骤，建议边学边做
3. **记录问题**：遇到问题时做好记录，这些都是宝贵的学习资料
4. **保持耐心**：量化交易是一个需要持续学习和实践的过程

## 💡 前置知识

- 基础的 Python 语法
- 简单的命令行操作
- Docker 基本概念（部分教程需要）
- 加密货币交易基础（推荐）

## ⚠️ 重要提示

本教程仅供学习和研究使用，不构成任何投资建议。量化交易存在风险，实盘交易可能导致资金损失。

**重要提示**：
- ⚠️ 建议先使用 **Dry-run 模式**充分测试
- ⚠️ 实盘交易前务必用小额资金测试
- ⚠️ 加密货币市场波动大，请做好风险控制
- ⚠️ 不要投入超过你承受范围的资金
