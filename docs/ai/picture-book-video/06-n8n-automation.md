# 06 n8n 自动化工作流

本章节将介绍如何在 n8n 中设计和构建完整的自动化工作流，串联故事编写、分镜图生成、视频生成、配音生成等所有步骤。

## 📋 内容概要

### 工作流设计
- 分析完整流程的各个环节
- 设计工作流的节点结构
- 确定数据流转和存储方式
- 规划错误处理和重试机制

### 节点配置
- 配置 HTTP Request 节点调用各 AI 工具 API
- 配置 Code 节点处理数据转换
- 配置 File 节点管理文件
- 配置条件判断和循环节点

### 自动化触发
- 设置定时触发（如每天生成新故事）
- 配置 Webhook 触发
- 设置手动触发选项
- 配置工作流执行计划

### 数据管理
- 工作流数据存储
- 中间文件管理
- 结果文件组织
- 日志和监控

## 🔧 技术要点

- n8n 工作流设计
- API 集成和调用
- 数据流转和处理
- 错误处理和重试
- 文件管理系统
