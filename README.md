# Frank Quant - 量化交易研究与实盘记录

一个专业的量化交易学习平台，提供教程、工具、实盘记录和书籍推荐。

## 🌟 网站特色

- **完整的教程体系**：从零开始学习量化交易
- **实用的工具代码**：开源的量化交易代码库
- **详细的实盘记录**：真实的交易日志和绩效分析
- **精选的书籍推荐**：系统化的学习资源

## 📚 内容结构

### 教程部分
- **量化交易基础**：市场基础、量化方法、风险管理
- **策略开发**：策略设计、算法实现、策略优化
- **回测技巧**：数据准备、绩效评估、参数优化
- **工具配置**：环境搭建、平台使用、数据源配置

### 工具部分
- **代码库**：数据处理、策略框架、风险管理
- **脚本集合**：数据收集、分析工具、自动化脚本
- **平台指南**：Freqtrade、Backtrader等平台使用

### 实盘记录
- **2024年记录**：完整的年度交易记录
- **2025年记录**：持续更新的交易日志
- **月报汇总**：定期的绩效分析和总结

### 书籍推荐
- **推荐书单**：精选的量化交易书籍
- **读书笔记**：详细的学习心得
- **资源下载**：相关资料的下载链接

## 🚀 快速开始

### 本地开发

```bash
# 克隆项目
git clone https://github.com/frank-quant/quant-website.git
cd quant-website

# 安装依赖
npm install

# 启动开发服务器
npm run start
```

### 构建部署

```bash
# 构建生产版本
npm run build

# 部署到GitHub Pages
npm run deploy
```
